# Project Docs

This folder stores long-lived project context that should not live in `AGENTS.md`.

## Start Here

- AI workflow: `workflows/ai-flow.md`
- Git, Linear, and GitHub workflow: `workflows/git-linear-github.md`
- Architecture docs: `architecture/README.md`
- Architecture overview: `architecture/overview.md`
- Product feature vision: `product/assistant-feature-vision.md`
- Implementation history: `history/implementation-log.md`

## What Belongs Here

Use docs for architecture boundaries, workflow rules, implementation history, terminology, and decisions that future work should remember.

Do not use docs for temporary notes, duplicated code comments, or ideas that are not yet actionable.
